## Findings

### F1 — Packaged app launched unsandboxed with an empty store

The release package was signed without `--entitlements`, so the built app had
no `com.apple.security.app-sandbox` entitlement. It read/wrote:

```text
~/Library/Application Support/Asterisma/
```

instead of the real sandbox container. That store was empty, which is why the
first-run wizard appeared despite the 7-book library.

**Fixed and verified:** `scripts/package-release.sh` now signs with
`AsterismaV1.0.entitlements` and refuses to publish a package whose signed app
does not carry the sandbox entitlement. The rebuilt package
(`cc17f990…`) skipped the false onboarding and loaded the real library.

### F2 — Freeze at the reading-goal step

The app froze after the owner reached the “set a reading goal” onboarding step.
No crash report was written, so this is a hang. The process had exited by the
time evidence was collected.

**Fixed:** the Finish button set the AppStorage flag but never called
`dismiss()`, so the final onboarding step was a dead end. `OnboardingView` now
dismisses the sheet. The false onboarding itself was caused by F1.

---

### F3 — Desktop EPUBs grayed out in the Add Book panel

The `.epub` files in `~/Desktop/library tests/` are **unzipped EPUB package
directories**, not zip archives. macOS identifies them as
`com.apple.ibooks.epub` / `public.directory`; the panel used
`canChooseDirectories = false` and the importer only handled zip archives, so
the files were grayed out and unselectable.

**Fixed in the final candidate:** the panel now allows `public.directory` (not
just `public.folder`), and both `BookImporter.importEPUB` and `EPUBPackage.open`
parse an unzipped `.epub` directory in place. Regression pin:
`FolderEPUBImportTests` passes. Owner retest pending.

### F4 — Toolbar absent and green zoom inert in windowed mode

`.windowStyle(.hiddenTitleBar)` hid the toolbar in windowed mode, and the main
window had no minimum size; macOS restored a 900x450 frame. The green zoom
button had nothing usable to zoom.

**Fixed in the next candidate:** standard title bar restored, main content
minimum 1000x680, `.windowResizability(.contentMinSize)`, and a 1200x780
default size. Modal sheets also need to remain reachable.

### F6 — Add Book reported "Unsupported file type" for the parent folder

The picker allowed ordinary directories because `.directory` was in
`allowedContentTypes`. Selecting `library tests` returned the folder itself,
which is not a book. The picker now admits PDFs, zipped EPUBs, and declared
iBooks EPUB packages only; ordinary folders are navigable but not selectable.
If a folder is ever passed in, the importer now says “not an EPUB package”
instead of “Unsupported file type.”
